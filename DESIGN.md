# Hiretivo signed-in UI

Use semantic color utilities across signed-in Hiretivo, including dialogs, menus, and toasts. Public pages, sign-in, and document themes each keep their own styling.

| Role | Color |
| --- | --- |
| Page and preview canvas | `#f7f8f9` |
| Surfaces and controls | `#ffffff` |
| Borders and hover | `#dcdfe4` and `#f1f2f4` |
| Primary action and hover | `#0c66e4` and `#0055cc` |
| Selection and focus | `#e9f2ff` and `#388bff` |
| Primary, secondary, and disabled text | `#172b4d`, `#44546f`, and `#8993a4` |
| Success, warning, and danger accents | `#1f845a`, `#f5cd47`, and `#c9372c` |

Use darker text on tinted feedback surfaces and visible borders on inputs and switches. Keep labels alongside application status colors.

The Resume workspace puts Fit to one page and the Themes, Customize, and Sections tabs before the preview. At 960px of available workspace width, the controls occupy a 320px left column. At smaller widths they stack above the preview, with the tab content scrolling within the panel. Keep the panel and preview positions stable when tabs change. New application uses the shared palette and keeps its existing workflow.
